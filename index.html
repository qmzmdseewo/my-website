GitHub Pages 示例网页

一个页面同时展示：文字 · 图片 · 视频 · 音频

文字

这是一段文字内容

GitHub Pages 可以完整承载网页上的文字内容。这里可以放你的介绍、故事、说明文档、日志等等，样式都能自由排版。

只要把 HTML 文件放到 GitHub 仓库并开启 Pages，访客通过浏览器就能打开看到这些文字。

图片

这是一张图片

图片推荐用图床外链（不占 GitHub 容量），也可以直接放进仓库文件夹。

视频

这是一段内嵌视频（B站）

视频不打包进 GitHub，用 B站 iframe 嵌入，节省空间、加载也快。

音频

这是一段音频

音频用外部 mp3 链接播放，访客可直接点播放。
